Critical Finding

Fullness is mathematically false for SemiNormedGrp. Counterexample: summation on c00(ℕ,ℤ) is continuous and additive but not bounded. Root cause: no scalar multiplication by a dense subfield. The immediate obstruction disappears over ℝ; over ℂ a target retaining scalar linearity is required.

Key Findings

1. Monoidal structure already in Mathlib

The proof uses the internal hom rather than stalks. Works for any closed braided target category, avoiding the fact that CompHaus with the coherent topology does not have enough points.

2. A bridge in the pinned Mathlib version

The project did not find an existing packaged construction connecting the relevant normed-group and condensed components in Mathlib v4.28.0; no global priority claim is made.

3. Fullness fails for seminormed groups

A machine-checked counterexample: the condensed realization sees continuous additive maps that need not be bounded in SemiNormedGrp.

4. Finite products supplied for the pinned Mathlib version

Constructed from scratch with explicit operator norm bounds via Finset.sup.

5. Frobenius algebra data formalizes cleanly

The Frobenius algebra data extends Mathlib's existing monoid/comonoid infrastructure. The symmetric monoidal classification theorem is not yet formalized.

Contributor Roadmap

Tier 1: Days to weeks

1.1 Preserve equalizers. Continuous maps into ker(f-g) biject with equalizing maps.

1.2 Complete the ordinary presentation functor, then separately formalize monoidal coherence and the universal property.

1.3 Project integration. Proper imports and deduplication.

Tier 2: Weeks to months

2.1 Scalar-sensitive normed-space and condensed-module categories; prove any fullness claim with explicit scalar hypotheses.

2.2 Concrete Frobenius object in CondensedAb.

2.3 State a precise analytic exactness theorem with explicit source category, tensor product, and hypotheses.

Tier 3: Months

3.1 Projective tensor product of normed spaces (not in Mathlib).

3.2 Embedding is monoidal. Requires 3.1.

3.3 Identify and port a precise LTE-related theorem with its original hypotheses.

Tier 4: Research Frontier

4.1 Smooth cobordism categories in Lean.

4.2 Concrete Chern-Simons valued in CondensedAb.

4.3 Factorization algebras with liquid vector spaces.
