Liquid Vector Spaces as a Target Category for Topological Quantum Field Theories

A Lean-Checked Exploratory Formalization
Sean Mahdavian · March 2026 · Lean 4 + Mathlib v4.28.0 · 6 sessions, ~1380 lines, 0 axioms

We propose liquid vector spaces (Clausen-Scholze) as a replacement target category for topological quantum field theories in the infinite-dimensional regime. Topological vector spaces can be poorly behaved for homological and analytic constructions. Condensed abelian groups provide an abelian symmetric monoidal setting, but ordinary TQFT gluing itself is functorial composition and does not require exact sequences. This repository proves no general tensor-exactness theorem.

We report on formal verification using Lean 4 and Mathlib v4.28.0, assisted by Harmonic's Aristotle system. The project machine-checks an instantiation of Mathlib's existing symmetric monoidal structure on condensed abelian groups. Five sorry placeholders remain elsewhere in the project.

01   Introduction

The Problem

A topological quantum field theory, in Atiyah's formulation, is a symmetric monoidal functor Z : Cob(d+1) → C from a cobordism category to some target category C. When C is the category of finite-dimensional vector spaces, the theory is clean. Dijkgraaf-Witten, Reshetikhin-Turaev, and Turaev-Viro all work here.

But the physically interesting theories refuse to stay finite-dimensional. Chern-Simons theory with non-compact gauge group SL(2,ℂ), quantum gravity partition functions, path integrals over infinite-dimensional moduli. The natural target becomes topological vector spaces. And here the trouble starts.

The category TopAb of topological abelian groups is not abelian. A continuous bijective homomorphism need not have a continuous inverse. This obstructs naive homological algebra and can complicate particular infinite-dimensional constructions. It does not make ordinary functorial TQFT gluing ill-defined.

The Proposed Solution

Clausen and Scholze's condensed mathematics provides the fix. Condensed abelian groups form an abelian category. Liquid vector spaces admit an exact completed tensor product (the Liquid Tensor Experiment, Lean-verified 2022). Such exactness can be valuable in additional derived or analytic constructions, but it is not an axiom of ordinary TQFT and is not proved here.

02   Formal Verification Results

CondensedAb Is a Symmetric Monoidal Category

Theorem (formally verified). CondensedAb admits a symmetric monoidal structure via sheafified pointwise tensor. The sheafification functor is monoidal and braided.

The construction uses four layers of existing Mathlib infrastructure:

  1. Presheaf monoidal structure. Pointwise tensor on CompHausop → Ab.
  2. Sheafification as localization. presheafToSheaf is a localization functor for J.W.
  3. W is monoidal. J.W is closed under tensoring, proved via internal hom (not stalks).
  4. Localized monoidal category. General machinery from localization theory.
instance condensedAb_W_isMonoidal :
    ((coherentTopology CompHaus).W
      (A := ModuleCat (ULift ℤ))).IsMonoidal :=
  GrothendieckTopology.W.monoidal

instance condensedAb_monoidalCategory :
    MonoidalCategory CondensedAb :=
  Sheaf.monoidalCategory _ _

Six lines. Zero sorries. The internal hom argument means the result holds for any closed braided target category, even where stalks are not well-defined.

TQFT Transfer Theorem

Theorem (sorry-free). If Z : S → C is a TQFT and F : C → D is a braided monoidal functor, then Z composed with F is a TQFT valued in D. Proved purely from Mathlib's typeclass inference.

The Abelianness Advantage

Theorem (sorry-free). In any abelian category, mono + epi = iso. This formalizes the exact obstruction that makes TopAb fail as a TQFT target.

Critical Finding

The embedding SemiNormedGrp → CondensedAb is faithful but NOT full. Counterexample: summation on eventually-zero integer sequences is continuous and additive but not bounded. Over ℝ the immediate boundedness obstruction disappears; over ℂ, CondensedAb forgets complex linearity, so a scalar-sensitive target is required.

04   Why Liquid Vector Spaces

Chern-Simons with non-compact gauge group. SL(2,ℂ) Chern-Simons produces infinite-dimensional state spaces where gluing requires exact sequences of distribution spaces, exactly where TopVect fails.

Factorization algebras. Costello-Gwilliam's framework relies on completed tensor products. Liquid vector spaces provide an exact tensor product in a well-behaved abelian category.

Perturbative invariants. Configuration space integrals produce distributional forms. The condensed framework offers cleaner multiplicative structure.
